# Page Override: Auth (`/login`, `/signup`)

## Hero
- Logo + "Welcome back" / "Create account"
- Sub: "Sign in to continue learning"

## UX
- Google sign-in button with official colors
- Theme toggle top-right
- Inputs: 16px font-size, visible labels, inline errors in `.alert-error`
- Primary submit full-width; disabled while submitting
- Focus order: theme → form fields → actions → switch link

## Brand
- Auth gradient uses `--auth-gradient` (pink-soft light / red tint dark)
- No emojis in buttons
