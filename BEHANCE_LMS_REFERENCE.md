## 5. User Research — 5W Framework

### WHERE?
- **Online** — remote learning via laptop / digital platform

### WHY? (by audience segment)

#### Adult learners (price / quality focused)
- Price–quality ratio is a primary decision factor
- Reviews and reputation matter
- For older students with limited income, choosing the right teacher/school is critical — wrong choice wastes scarce money

#### Younger learners / parents
- **Children choose** based on:
  - Whether they like the site/LMS visually and atmospherically
  - The approach to teaching
- **Parents buy** based on:
  - Whether the child likes it
  - Whether the school appears competent and prestigious

## 7. Visual & UI Direction

| Element | Style |
|---------|--------|
| **Overall feel** | Clean, modern, minimal, airy — lots of whitespace |
| **Page background** | Off-white / cream with soft peach/orange decorative blobs |
| **Primary accent** | Deep forest green (~`#005C4B`) for headers, nav, row labels |
| **Secondary accents** | Pastels — peach/apricot (~`#FFDAC1`), mint (~`#DFF3E3`), lavender (~`#E8D9F2`) for content zones |
| **Typography** | Lexend Deca (style guide); modern sans-serif in UI mockups |
| **Components** | Rounded cards, pill/tag chips, grid-based matrix layouts |
| **Iconography** | Small colored geometric markers (squares, pins) instead of plain bullets |
| **Persona cards** | Light mint/teal card backgrounds (~`#E0F2F1`), dark green headings, orange-red bullet accents |
| **Dashboard preview** | Calendar/timeline grid (Feb / Mar / Apr columns) — schedule-oriented layout |

### Dashboard (hi-fi mockups)

| Zone | Design |
|------|--------|
| **Sidebar nav** | Dark green vertical nav, white icons + labels, orange active state, red notification badges (e.g. Messages "3") |
| **Top header** | Search, notifications, profile on white bar |
| **Main area** | Card widgets on light background — line chart for activity/grades, course progress cards |
| **Schedule** | Month columns (Feb / Mar / Apr) with grid cells for sessions |

### Course catalog (hi-fi mockups)

| Element | Design |
|---------|--------|
| **Card layout** | Horizontal: large icon/thumbnail block (dark green) + content column |
| **Title** | Bold, e.g. "Working with After Effects. Basic course" |
| **Pill tags** | Level + type (e.g. "elementary", "instrumental") — colored backgrounds |
| **Metrics line** | `120 lessons (40 h) \| 5 practical modules` |
| **CTAs** | Dual buttons: "Learn more" (outline) + "Buy now" / primary (filled green) |
| **Progress** | Line/bar charts on dashboard for ongoing courses |

### Video / lesson (inferred from case study)

| Element | Design |
|---------|--------|
| **Player** | Central 16:9 video area, clean chrome |
| **Progress** | Visible watch/completion state before unlocking next step |
| **Async model** | Short recorded lessons; full curriculum on-demand |
| **Participants** | Circular avatars in community/messages areas |

### Style guide page

- **Font:** Lexend Deca (Behance) — Iron Lady uses Gemunu Libre + Fira Sans instead
- **Colors in guide:** Mint, orange, dark teal, yellow accents
- **Principles:** "Absence of Strict Hierarchy", collaborative tone

### Design language summary
- **Reduce cognitive load** — soft pastels separate sections without heavy borders
- **Strong primary for structure** — dark green anchors navigation and category headers
- **Friendly but professional** — decorative background shapes soften a technical/education context
- **Research-first presentation** — case study walks from goals → research → persona → UI

## 10. Mapping to Iron Lady LMS

Use this reference for **layout and UX patterns**, not colors or copy. Align with `COMPANY_CONTEXT.md` and `.cursor/rules/iron-lady-brand-context.mdc`.

| Behance pattern | Iron Lady LMS application |
|-----------------|---------------------------|
| Async short lessons | MBW weekly tasks, recorded MasterClass model, lesson chunks |
| Dashboard + calendar | Student Home events, learner calendar, streak/analytics block |
| Card-based profile | Student profile, program badge (MBW / LEP / 100BM), CX moderator view |
| Goals / frustrations / persona framing | Onboarding copy, empty states, program selection messaging |
| Schedule grid | Event calendar, MBW quarterly module timeline |
| Pill/tag chips for process steps | Admin filters, program tags, task status pills |
| Pastel section backgrounds | Map to Iron Lady cream `#F7F6E4`, beige `#EBEADC`, pink soft `#F2DEDE` |
| Strong primary headers | Iron Lady red `#F52929` / deep `#C8102E` instead of forest green |

### Suggested implementation priorities
1. **Student dashboard** — card grid: welcome, active course, upcoming events, streak summary
2. **Calendar-first schedule** — month/week view for live sessions and deadlines
3. **Profile / goals card** — B-HAG, program tier, community CTA
4. **Soft section backgrounds** — cream/beige zones on Home and course detail
5. **Short-lesson progress** — compact lesson rows with clear completion state (already partially in MBW journey)

### Do not copy
- Forest green palette (off-brand for Iron Lady)
- Behance designer’s icons, illustrations, or exact layouts without permission
- IT-school-specific copy (Iron Lady is women’s leadership, not IT bootcamp)
