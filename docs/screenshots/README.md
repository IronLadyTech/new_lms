# Screenshots for the LMS Walkthrough Deck

Slide-style guide: **2–3 screenshots across the top of each slide, numbered steps below.**

## Where to save them

Put PNG files in this folder (`docs/screenshots/`) using the **exact filenames** below.

Naming: `A01-a.png` = Part A, slide 01, first screenshot (left to right).

## How to capture

| Part | Device | Why |
|---|---|---|
| **A — Learner** | **Mobile**, iPhone 14 Pro / 393px (browser device toolbar) | Matches the phone-screenshot look; learners are mobile-first |
| **B — CX** | **Desktop**, ~1440px | Tables and charts need the width |
| **C — Admin** | **Desktop**, ~1440px | Same |

- Save as **PNG**
- **Blur or use test data** for real names, emails, phone numbers
- Send in batches if easier — I'll build slides as they arrive
